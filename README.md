# Git Learning Project

这是一个用于学习 Git 与 GitHub 协作的基础仓库。

## 当前内容

- `README.md`：项目说明
- `GIT_GUIDE.md`：Git、GitHub 和 Visual Studio 使用指南
- `.gitignore`：需要忽略的本地或构建文件

## 建议的后续步骤

1. 在 GitHub 创建一个空仓库，不要勾选自动创建 README、`.gitignore` 或 License。
2. 按 `GIT_GUIDE.md` 中的命令绑定远程仓库。
3. 使用 Visual Studio 的 Git 菜单完成提交、同步和分支管理。
